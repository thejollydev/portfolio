// 01  —  Profile

Builder first, founder now.

I've been building software since I was a teenager. Before I made it my full-time craft, I spent 10+ years in sales — which turned out to be an asset, not a detour. I read what people actually need, translate it into what to build, and stay focused on the outcome, not just the code.

Today I'm the founder of BezaCore Labs, a DevOps, AI/agent & software-development studio. My work spans the full arc of shipping modern software: Python / FastAPI backends and REST APIs, LLM-integrated agent pipelines and RAG systems, and the production cloud infrastructure — self-hosted or on GCP — to run all of it reliably.

I hold an uncommon advantage: I can take a project from a blank repo to a running production service on infrastructure I built and automated myself. My homelab, BezaForge, is a real private cloud — Proxmox, GPU-passthrough local LLM inference, containerized services behind Traefik, full observability — codified end-to-end with Terraform and Ansible. I learn by shipping.
